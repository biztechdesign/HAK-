Overview

Design principles

Every component decision is checked against these eight principles.

inventory_2

Product first

Photography and accurate product data persuade; the interface stays quiet.

search

Two speeds of discovery

SKU search and filters for known needs; occasions, recipients and collections for inspiration.

arrow_forward

One honest next step

Each card and section ends in one clear action that matches how HAK Plus takes orders.

print

Capability, shown

In-house branding is the differentiator: show process, methods and results.

verified

Proof or nothing

Claims, logos and figures appear only once approved. Empty sections are hidden.

tune

Built to be configured

Sections, campaigns and occasions switch on and off without breaking layout.

language

Bidirectional by default

Logical properties, mirrored directional icons, text that can grow by about 30%.

business

Corporate, not consumer

Specifications, quantities, branding and approval before impulse, discounts and decoration.

Rules

  • Sentence case for headings, labels, navigation and buttons.
  • No arbitrary sizes — use the scale. Minimum 12 px (captions only).
  • Tabular numerals (.hk-num) for prices, SKUs, quantities.
  • Uppercase only for very short codes, never for headings.

Iconography

Material Symbols Rounded only — weight 300, fill 0, grade 0, optical size matched to rendered size. The variable font is loaded with the weight axis pinned at 200, so the thin stroke is real, not simulated. Filled icons are reserved for active states (for example a saved wishlist item).

Motion

Motion confirms an action or shows where something came from. No decorative loops, parallax or autoplay. Under prefers-reduced-motion: reduce all transitions collapse to near-instant.

Moderate · 280 ms · enter — drawers, dialogs, accordions
Standard · 200 ms · exit — surfaces leaving
Slow · 400 ms — only for large surfaces, rarely

Live examples elsewhere: button hover, product image hover (3% scale, no layout shift), tab underline, accordion height (CSS grid rows), drawer and dialog entry, wishlist fill.

      B2B newsletter form (outlined floating labels)

      D-115, D-116. The same markup as the homepage. .hk-field--float is an outlined field, 48 px high, with the value vertically centred (Inter 16 px). An empty, unfocused field shows its <label for> inside at 15 px. On focus, when filled or when autofilled, the label moves onto the top border at 12 px (weight 500). Its background, --_float-bg, is set to the surface behind the field, which cuts a clean notch in the border: white on light surfaces, --hk-color-bg-brand-deep in the newsletter. The label is absolutely positioned, so it never shifts layout. The move takes 200 ms (--hk-duration-standard), with none under reduced motion. Focus is one 2 px ring (border plus a 1 px shadow) in the accessible orange on dark and indigo on light, replacing the border plus offset outline. Errors turn the border and label to the error colour and add a message below. Example values appear as placeholders only on focus. Browser autofill tint is neutralised so the field stays outlined.

      RTL rules
      ElementRule
      Spacing and positionLogical properties only (margin-inline-start, inset-inline-end, text-align: start).
      IconsMirror arrows, chevrons and “next/back” with .icon-dir. Don’t mirror search, cart, check, media or brand icons.
      Numbers, SKUs, phone, emailWrap in dir="ltr" so digits and “+971” never reorder.
      KeyboardArrow-key navigation in tabs and swatches follows visual direction.
      TypographyIBM Plex Sans Arabic via :lang(ar); +0.15 line height; no negative tracking; weight ≤ 700 for display.
      Not mirroredLogo, product photography, charts, media controls, clocks.

      Accessibility

      Target WCAG 2.2 AA. Full guidance in documentation/accessibility-guidelines.md.

      Contrast

      Text 4.5:1, large text and UI boundaries 3:1. Ratios calculated live in the colour section. Orange #F36A35 never carries white text.

      Keyboard

      Everything operable by keyboard; visible 2 px focus ring with 2 px offset; skip link; Escape closes overlays; arrow keys inside composite widgets.

      Targets

      44 × 44 px for common actions; 24 × 24 px minimum with spacing (WCAG 2.5.8). Swatches use a 32 px hit area.

      Semantics

      Native elements first (button, a, dialog, fieldset). ARIA only for tabs, combobox, menus, switches and radiogroups.

      Forms

      Persistent labels, linked help and errors, error summary with focus, autocomplete tokens.

      Motion and zoom

      Reduced-motion respected; layouts reflow at 320 CSS px and 200% zoom without horizontal page scrolling.
